# Chapter 11: 视频、复合对象与动作（§12–14）

## Core Idea
除静态图元外，OFD 还支持**视频对象**、**复合对象**（将多个图元打包成可复用单元）和**动作**（交互行为：跳转/附件/URI/播放音视频）。动作可挂在大纲节点、文档、页、注释与图元上，形成交互。

## Frameworks Introduced
- **复合对象 CompositeObject（§13）**：把路径/文字/图像/视频等组合成一个对象，内部可再嵌套，被引用时整体绘制。
  - When to use: 复用一组固定图元（如公司 Logo、签章图形）时，打包为复合对象。
- **动作 Action（§14）**：事件触发的行为，类型含跳转（GoTo）、附件（Attachment）、URI、播放音频、播放视频。
  - When to use: 实现目录跳转、超链接、嵌入媒体播放时。

## Key Concepts
- **视频对象（§12）**：引用多媒体资源中的视频，定位与图像类似（Boundary/CTM），可带播放控制。
- **复合图元 CompositeGraphicUnits**：在资源中定义的矢量图像，被复合对象引用（见 §7.9）。
- **动作类型（§14）**：
  - 跳转动作：指向文档内位置（Dest）。
  - 附件动作：打开附件。
  - URI 动作：打开外部链接。
  - 播放音频动作 / 播放视频动作。
- **事件类型**：文档打开（DocOpen）等（见文档根 `Action` 节点与表52 事件类型）。

## Mental Models
- 复合对象像 **group/Symbol**：一组图元作为一个可引用单元。
- Think of `Action` as an **event handler**: trigger → behavior (goto/uri/play).

## Anti-patterns
- **把复合对象当普通图元直接绘制**：需先解析引用再展开内部图元。
- **忽略动作悬挂点**：动作可挂在多处（文档/页/大纲/注释），需按上下文路由。

## Key Takeaways
1. 视频对象引用多媒体资源，定位同图像。
2. 复合对象打包复用图元，渲染前展开。
3. 动作五类：跳转/附件/URI/播音频/播视频。
4. 动作可挂在文档、页、大纲、注释、图元多处。
