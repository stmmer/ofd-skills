# Chapter 1: 范围、引用文件与术语（§1–4）

## Core Idea
标准界定了 OFD 的适用范围（版式文档的长期保存与交换）、规范性引用、核心术语与缩略语。实现前先明确：OFD 面向**版式固定、所见即所得**的电子文件，不定义版面重排。

## Frameworks Introduced
- **版式文档定位**：OFD 关注版面固定呈现，与流式文档（重排）区分；适合存档、凭证、公文。
  - When to use: 判断某需求是否适合 OFD——需要"版面不变"才选 OFD。

## Key Concepts
- **范围（§1）**：规定电子文件存储与交换的版式文档格式要求。
- **规范性引用文件（§2）**：本标准依赖的其他标准（如 ZIP、GB 18030、GB 13000、W3C XML 等），实现需一并满足。
- **术语和定义（§3）**：版式文档、页面、图元、资源、签名等核心词的定义。
- **缩略语（§4）**：如 OFD、XML、ZIP、GB 等。

## Mental Models
- OFD = **fixed-layout exchange format**：版面即契约，跨设备一致。
- Think of 版式 vs 流式 as **PDF-like vs HTML-like**.

## Anti-patterns
- **把 OFD 当重排格式**：它不保证内容重排，别指望响应式布局。
- **忽略规范性引用**：ZIP/XML/编码等底层规范同样约束实现。

## Key Takeaways
1. OFD 是版式文档格式，版面固定、跨平台一致。
2. 适用存档/凭证/公文等需"所见即所得"场景。
3. 实现须同时满足引用的底层规范（ZIP、XML、GB 18030 等）。
4. 先吃透术语，再读后续结构章节。
